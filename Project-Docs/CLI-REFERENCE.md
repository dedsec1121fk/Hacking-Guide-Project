# Optional CLI Reference

The normal Hacking Guide Project interface does not require these options. Start `Hacking Guide Project.py` and use its numbered menus.

The command-line interface remains available for automation, scripts and power users.

```bash
python "Hacking Guide Project.py" --language en --search "Kerberos"
python "Hacking Guide Project.py" --language both --search "OAuth"
python "Hacking Guide Project.py" --module 72
python "Hacking Guide Project.py" --path termux
python "Hacking Guide Project.py" --categories
python "Hacking Guide Project.py" --progress
python "Hacking Guide Project.py" --doctor
```
