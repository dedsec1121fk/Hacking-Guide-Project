# Hacking Guide Project — Ελληνικά

Η ελληνική έκδοση περιλαμβάνει **140 αριθμημένα μαθήματα** σε 11 κατηγορίες. Οι αριθμοί μαθημάτων είναι ίδιοι με την αγγλική έκδοση.

Οι διεθνείς τεχνικοί όροι όπως OAuth, Kerberos, eBPF, API, CORS και Kubernetes διατηρούνται συχνά στα Αγγλικά για τεχνική ακρίβεια και ευκολότερη αναζήτηση documentation.

## Ο πιο εύκολος τρόπος χρήσης

Από το root του project ξεκίνησε:

```bash
python "Hacking Guide Project.py"
```

Μετά χρησιμοποίησε μόνο τα αριθμημένα menus. Δεν χρειάζεσαι flags αναζήτησης ή commands για να ανοίγεις μαθήματα.

Η αρχική οθόνη έχει **Συνέχεια**, **Αναζήτηση**, **Κατηγορίες**, **Δημοφιλή Θέματα**, **Διαδρομές Μάθησης**, **Bookmarks**, **Πρόοδο & Πρόσφατα**, **Γρήγορους Οδηγούς**, **Όλα τα Μαθήματα** και **Γλώσσα / Ρυθμίσεις**.

Στην αναζήτηση μπορείς να γράψεις απλές λέξεις, να επιλέξεις έτοιμο θέμα με αριθμό, να ξανανοίξεις πρόσφατη αναζήτηση, να ψάξεις ταυτόχρονα Ελληνικά + English ή να μεταβείς απευθείας σε αριθμό μαθήματος.
