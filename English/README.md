# Hacking Guide Project — English

The English edition contains **140 numbered modules** in 11 category folders. Module numbers are global and match the Greek edition.

## Easiest way to use it

From the project root, start:

```bash
python "Hacking Guide Project.py"
```

Then use only the numbered menus. No search flags or module commands are needed.

The home screen provides **Continue**, **Search**, **Categories**, **Popular Topics**, **Learning Paths**, **Bookmarks**, **Progress & Recent**, **Quick Guides**, **All Lessons**, and **Language / Settings**.

Search lets you either type normal words, choose a popular topic, reopen a recent search, search both languages, or jump to a module number. Results open directly by number.
